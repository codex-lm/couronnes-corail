# Credits and provenance

## Kimi Games

Concept, rules, data architecture, deterministic engine, local AI, Canvas/DOM interface, EN/FR/ES text, synthesized audio, Blender Python modeling, original materials and texture, GLB exports, isometric renders, cover, tests and browser verification were created with Kimi for this one-off mission.

The project is an original creation for Kimi Games. It is not based on another published game or external asset pack.

## Original asset kit

- Six sculpted reef and rock variants.
- Four ship classes with distinct silhouettes and three faction sail/emblem treatments.
- A modular stilt port, quays, docks, shell house and crane.
- Five standard buildings and one great lighthouse.
- Three ruin/discovery sites: archive, supply cache and tide beacon.
- Sails, beacon, crates and other harbor accessories.

The editable `.blend` files, generator script, GLB exports, generated nacre texture and rendered PNGs are retained in the repository. Navigation, sail, impact, construction and lighthouse-activation animation data are included where applicable; 18 GLB files contain embedded animations. Equivalent lightweight feedback is rendered in the browser.

## Tools

Models and cover were generated and rendered with Blender 4.5.3 LTS. Blender is not included in the repository and no license to Blender itself is claimed. The optional export rebuild uses esbuild 0.25.11 (MIT) as a development-only tool; it is not a game runtime dependency. No third-party game runtime, font download, remote image, audio sample or external service is used.
